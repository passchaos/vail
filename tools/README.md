# Tools

## Table generators

Generated tables are checked in and must be regenerated rather than edited:

```sh
zig run tools/generate_p256_tables.zig
zig run tools/generate_p384_tables.zig
zig run tools/generate_ed25519_base_table.zig
zig run tools/generate_ed25519_verify_table.zig
zig run tools/generate_x25519_tables.zig
```

The generated files carry a `Generated by tools/...` header and are excluded
from `zig build fmt`/`check`. `tools/generated_manifest.txt` records their
expected SHA-256 values; run `zig build check-generated` after regenerating or
intentionally changing a checked-in generated file.

`src/x509/stringprep_data.zig` is generated from Unicode 3.2 and RFC 3454
tables. A checked-in generator is still pending; document the exact input files
and commands when adding one.

## Interoperability tools

`tools/interop/` contains minimal clients and servers used by the
`interop-*` build steps:

- TLS 1.2, TLS 1.3, and version-selecting clients/servers;
- QUIC TLS clients/servers;
- raw-public-key and ML-DSA variants;
- signature helpers for OpenSSL verification;
- `openssl_client_hello.sh` for OpenSSL ClientHello checks.

These tools are intentionally small and are not a general-purpose API example.
See `examples/` for that.

## Adding a tool

- Keep tools allocation-light and deterministic.
- Use fixed ports only when the build step serializes access.
- Document required environment variables and external binaries.
- Add a matching `interop-*` or `bench-*` step if the tool is part of a gate.
